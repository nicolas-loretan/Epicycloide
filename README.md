Ce programme permet de dessiner librement à la souris, puis de reproduire le dessin grâce à une animation d'épicycloïdes.

Il utilise les séries de Fourier pour calculer la taille et la vitesse de rotation de chaque cercle, afin de retracer le dessin initial.

Les annotations initiales du code n'étaient pas suffisamment approfondies pour permettre à n'importe qui de comprendre son fonctionnement. La version présentée ici comporte donc des commentaires plus détaillés, dont une grande partie a été générée à l'aide de l'intelligence artificielle.
